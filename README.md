# gost-skills

[![Тесты](https://github.com/maarshir/gost-skills/actions/workflows/tests.yml/badge.svg)](https://github.com/maarshir/gost-skills/actions/workflows/tests.yml)

Навыки для ИИ-агентов, которые проверяют оформление курсовых, ВКР, отчётов и списка литературы по ГОСТу и говорят, что не так и где. Работают в любом агенте со стандартом [Agent Skills](https://agentskills.io): Claude Code, Codex, Cursor, Gemini CLI и других.

Запрос агенту: «Проверь курсовую по ГОСТу, методичка требует 14 кегль» и файл .docx. Агент запускает скрипт навыка и объясняет, как исправить каждое место в Word. Вот настоящий вывод скрипта на учебном файле из `examples/` (ошибки внесены нарочно):

```
$ python skills/gost-report/scripts/check_docx.py example.docx
Проверка: example.docx, профиль «ГОСТ 7.32-2017»
Ошибок: 9, замечаний: 0

ОШИБКИ
1. Поле левое 20 мм, нужно 30 мм (п. 6.1.1)
2. Заголовок структурного элемента не по центру (п. 6.2.1)
   абзац 18 «ЗАКЛЮЧЕНИЕ»
3. Структурный элемент или раздел не с новой страницы (п. 6.2.1)
   абзац 18 «ЗАКЛЮЧЕНИЕ»
4. Точка после номера «1.1.» (п. 6.4.1)
   абзац 14 «1.1. Сравнение»
5. Шрифт Arial вместо Times New Roman (п. 6.1.1)
   абзац 17 «Метод А оказался точнее на выбранном на…» (раздел «1.1. Сравнение»)
6. Слово «Рисунок» в подписи пишется полностью (п. 6.5.7)
   абзац 13 «Рис. 1 - Схема поиска.» (раздел «1 Обзор методов»)
7. В подписи дефис вместо тире: «– Название» (п. 6.5.7)
   абзац 13 «Рис. 1 - Схема поиска.» (раздел «1 Обзор методов»)
8. Точка в конце подписи (п. 6.5.7)
   абзац 13 «Рис. 1 - Схема поиска.» (раздел «1 Обзор методов»)
9. Ссылка [3], а в списке источников их 2 (п. 6.16)
   абзац 19 «Сравнение показало, что метод А подходи…» (раздел «ЗАКЛЮЧЕНИЕ»)
```

## Установка

Claude Code:

```
/plugin marketplace add maarshir/gost-skills
/plugin install gost-skills@gost-skills
```

Другие агенты: `npx skills add maarshir/gost-skills` или скопировать папки из `skills/` туда, где агент ищет навыки (например, `.agents/skills/` в проекте).

Скриптам нужен Python 3.10+ и `pip install python-docx` (на 3.10 ещё `tomli`).

## Без агента

```bash
git clone https://github.com/maarshir/gost-skills && cd gost-skills
pip install -r requirements.txt
python skills/gost-report/scripts/check_docx.py работа.docx
python skills/gost-report/scripts/check_docx.py работа.docx --config методичка.toml --json
python skills/gost-bibliography/scripts/check_bibliography.py список.txt   # или работа.docx
```

Файл не меняется. Требования методички задаются коротким файлом настроек поверх ГОСТа: для работы [пример](skills/gost-report/assets/methodichka-example.toml) и [все ключи](skills/gost-report/references/config.md), для списка литературы [пример](skills/gost-bibliography/assets/methodichka-example.toml) и [все ключи](skills/gost-bibliography/references/config.md).

## Что было непросто

- **Узнать настоящий шрифт абзаца.** В разметке Word у фрагмента часто нет шрифта: он берётся из стиля символа, стиля абзаца, цепочки базовых стилей, значений документа или темы («шрифт основного текста» это ссылка на тему). Скрипт проходит всю цепочку, иначе он пропустил бы Calibri, заданный в стиле «Обычный».
- **Отличить подпись от ссылки.** «Рисунок 1 – Схема» это подпись, а «Рисунок 1 показывает схему» это текст. Подписью считается строка, где после номера идёт тире, точка, двоеточие или ничего.
- **Не ругаться на титульный лист.** У него своё оформление, поэтому проверка текста начинается с первого структурного элемента.
- **Показать место, а не номер страницы.** Номера страниц в файле нет, его считает Word при вёрстке. Поэтому место указано номером абзаца, началом текста и разделом: по началу текста абзац находится поиском.
- **Не путать знаки записи со знаками адреса.** В «https://example.com» есть и двоеточие, и две косые черты, но правила пробелов к ним не относятся. Перед проверкой знаков адреса, «URL:» и дата обращения закрываются заглушкой той же длины, поэтому позиции остальных символов не сдвигаются.
- **Тире в заглавии и тире между областями.** «Наука, 2021 – 256 с.» это пропущенная точка, а «Поиск – обзор методов» может быть частью заглавия. Если перед тире цифра или скобка, это ошибка, иначе замечание.
- **Тестовые файлы.** Чужие работы в репозиторий класть нельзя, поэтому тесты собирают правильную курсовую кодом, портят в ней одно место и проверяют, что скрипт нашёл именно его. Отдельный тест сверяет все SKILL.md со спецификацией.
