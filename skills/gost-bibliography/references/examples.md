# Образцы записей по видам источников

Схема и пример для каждого вида. Примеры вымышлены (авторы, названия, ISBN, адреса), настоящие только правила. Последняя область «– Текст : …» нужна, если её требует методичка.

Если каких-то данных нет (страниц, издателя, года), не выдумывать: спросить пользователя или прямо написать, чего не хватает.

## Книга одного, двух или трёх авторов

Схема: `Фамилия, И. О. Заглавие : сведения к заглавию / И. О. Фамилия, И. О. Фамилия. – Место : Издательство, Год. – Объём с. – ISBN. – Текст : непосредственный.`

```
Петров, П. П. Основы информационного поиска : учебное пособие / П. П. Петров, С. С. Сидоров. – Москва : Наука, 2021. – 256 с. – ISBN 978-5-02-040000-1. – Текст : непосредственный.
```

## Книга четырёх авторов

Запись начинается с заглавия, все четыре автора после косой черты.

```
Анализ текстов на Python : учебник / А. А. Иванов, Б. Б. Смирнов, В. В. Кузнецов, Г. Г. Орлов. – Москва : Наука, 2022. – 320 с. – Текст : непосредственный.
```

## Пять авторов и больше

Первые три и «[и др.]».

```
Методы машинного обучения : монография / А. А. Иванов, Б. Б. Смирнов, В. В. Кузнецов [и др.]. – Санкт-Петербург : Питер, 2020. – 312 с. – Текст : непосредственный.
```

## Под редакцией, без автора

```
Информатика : учебник / под редакцией П. П. Петрова. – 3-е изд., перераб. и доп. – Москва : Наука, 2023. – 480 с. – Текст : непосредственный.
```

## Статья из журнала

Сначала статья, после « // » журнал, год, номер, страницы. Вид содержания стоит перед « // ».

```
Сидоров, С. С. Сравнение методов ранжирования / С. С. Сидоров, А. А. Козлов. – Текст : непосредственный // Вестник информатики. – 2022. – № 3. – С. 15–20.
```

## Статья из сборника или материалов конференции

```
Козлов, А. А. Поиск по документам с учётом синонимов / А. А. Козлов. – Текст : непосредственный // Информационные технологии : материалы конференции (Москва, 12–13 апреля 2023 г.). – Москва : Наука, 2023. – С. 45–50.
```

## Статья в электронном журнале или на сайте

```
Орлов, О. О. Поиск по документам / О. О. Орлов. – Текст : электронный // Блог разработчика : [сайт]. – 2024. – URL: https://example.com/blog/search-2024 (дата обращения: 15.09.2026).
```

## Сайт или страница документации

```
Документация библиотеки для чтения .docx. – URL: https://example.com/docs/ (дата обращения: 15.09.2026). – Текст : электронный.
```

Если на странице есть год публикации, его ставят после названия сайта: «– 2024. –».

## Электронная книга в библиотечной системе

```
Петров, П. П. Основы программирования : учебник / П. П. Петров. – Москва : Наука, 2022. – 300 с. – ISBN 978-5-02-040000-2. – URL: https://example.com/book/123 (дата обращения: 15.09.2026). – Текст : электронный.
```

## Закон

```
Об информации, информационных технологиях и о защите информации : Федеральный закон № 149-ФЗ : принят Государственной Думой 8 июля 2006 года : одобрен Советом Федерации 14 июля 2006 года. – Текст : электронный // Официальный интернет-портал правовой информации. – URL: http://pravo.gov.ru (дата обращения: 15.09.2026).
```

Даты принятия и одобрения берут из текста самого закона на официальном портале.

## Стандарт

Схема: `Обозначение–Год. Заглавие : национальный стандарт Российской Федерации : издание официальное : утверждён и введён в действие Приказом ... от ... № ... : введён впервые : дата введения ... . – Место : Издатель, Год. – Объём с. – Текст : непосредственный.`

Реквизиты приказа, дату введения, издателя и объём брать с титула или со страницы стандарта на официальном портале, а не по памяти.

## Диссертация и автореферат

```
Петров, П. П. Методы поиска по документам : специальность 05.13.17 «Теоретические основы информатики» : диссертация на соискание учёной степени кандидата технических наук / Петров Пётр Петрович ; Московский университет. – Москва, 2020. – 180 с. – Текст : непосредственный.
```

## Иностранные источники

На языке оригинала, знаки те же. Страницы «P. 15–20», объём «300 p.».

```
Smith, J. Information Retrieval Basics / J. Smith. – London : Example Press, 2019. – 300 p. – Текст : непосредственный.
Brown, A. Ranking with Transformers / A. Brown, C. Green. – Текст : электронный // Journal of Search. – 2023. – Vol. 5, № 2. – P. 10–25. – URL: https://example.com/jos/5-2 (дата обращения: 15.09.2026).
```
