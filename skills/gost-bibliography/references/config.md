# Настройки под методичку

Профиль по умолчанию лежит в `assets/gost-7.0.100.toml`. Свой файл содержит только отличия и накладывается поверх профиля. Пример: `assets/methodichka-example.toml`.

```bash
python scripts/check_bibliography.py список.txt --config методичка.toml
```

| Раздел | Ключ | По ГОСТ | Что значит |
|--------|------|---------|------------|
| `[areas]` | `separator` | `"dash"` | Разделитель областей: `"dash"` ждать «. – », `"dot"` методичка разрешает точку, `"any"` не проверять |
| `[content_type]` | `required` | `false` | `true`: в каждой записи, кроме законов и стандартов, нужна область «– Текст : непосредственный.» или «электронный» |
| `[place]` | `allow_abbreviations` | `true` | `false`: «М.» и «СПб.» считаются ошибкой, нужно «Москва», «Санкт-Петербург» |
| `[order]` | `mode` | `"any"` | `"alphabet"`: по алфавиту, сначала кириллица, потом латиница |
| | `legal_first` | `false` | `true`: законы и стандарты в начале списка, их порядок между собой не проверяется |
| `[freshness]` | `max_age_years` | `0` | Сколько лет источнику допустимо; старые получают замечание. `0` не проверять. Законы и стандарты не считаются |

Строки в TOML пишутся в кавычках: `mode = "alphabet"`.
