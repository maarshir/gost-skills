# Список литературы по ГОСТ Р 7.0.100-2018

Требования вуза сильнее ГОСТа: если у пользователя есть методичка, она главная. Не выдумывай данных источника (авторов, год, издательство, страницы, ISBN, даты принятия закона): если их нет, спроси или прямо напиши, чего не хватает.

## Оформить запись

1. Определи вид источника: книга, статья из журнала или сборника, сайт, электронная книга, закон, стандарт, диссертация, иностранный источник.
2. Возьми схему и образец из [references/examples.md](references/examples.md) и подставь данные пользователя. Правила знаков и авторов с номерами пунктов в [references/rules.md](references/rules.md).
3. Проверь готовую запись скриптом, как описано ниже.

## Проверить готовый список

1. Спроси, есть ли методичка. Если есть, перенеси её отличия (полное название города, обязательное «Текст : …», алфавитный порядок, законы в начале, свежесть источников) в файл настроек по образцу `assets/methodichka-example.toml`. Все ключи в [references/config.md](references/config.md).
2. Запусти проверку. Скрипт только читает файл.
   ```bash
   python scripts/check_bibliography.py список.txt          # по записи в строке, номера «1.» можно оставить
   python scripts/check_bibliography.py работа.docx         # найдёт раздел «Список использованных источников»
   python scripts/check_bibliography.py список.txt --config методичка.toml --json
   ```
   Для .docx нужен `pip install python-docx`, для текста хватает Python 3.10+ (на 3.10 ещё `tomli`). Код выхода 1 значит «есть ошибки», 0 значит «ошибок нет» (замечания возможны), 2 значит «файл не прочитан или список не найден».
3. Перескажи результат по записям: номер записи, что не так, как исправить. Код каждого нарушения и правильный вариант есть в таблицах [references/rules.md](references/rules.md). Если пользователь просит, выдай исправленные записи целиком.
4. Ошибки это прямые расхождения со стандартом или настройками. Замечания показывай с оговоркой: там стандарт допускает варианты или скрипт не уверен (например, тире в заглавии).

## Что скрипт не проверяет

- Верны ли сами данные: авторы, год, издательство, страницы. Их можно сверить только с источником.
- Есть ли на каждую запись ссылка в тексте работы: это проверяет навык gost-report по .docx.
- Сокращения слов в записи (ГОСТ Р 7.0.12) и порядок областей внутри записи.
- Курсив и другие выделения шрифтом.
