# Настройки проверки под методичку

Профиль по умолчанию лежит в `assets/gost-7.32.toml`. Свой файл настроек содержит только то, что отличается: скрипт накладывает его поверх профиля. Пример: `assets/methodichka-example.toml`.

```bash
python scripts/check_docx.py работа.docx --config методичка.toml
```

## Ключи

| Раздел | Ключ | По ГОСТ | Что значит |
|--------|------|---------|------------|
| `[page]` | `width_mm`, `height_mm` | 210, 297 | Размер листа |
| | `margin_left_mm`, `margin_right_mm`, `margin_top_mm`, `margin_bottom_mm` | 30, 15, 20, 20 | Поля |
| | `tolerance_mm` | 1 | Допуск по полям и размеру |
| `[text]` | `font` | Times New Roman | Шрифт; пустая строка отключает проверку |
| | `size_min_pt` | 12 | Минимальный кегль |
| | `size_pt` | 0 | Точный кегль; 0 значит «любой не меньше минимума» |
| | `line_spacing` | 1.5 | Междустрочный интервал (множитель) |
| | `indent_cm`, `indent_tolerance_cm` | 1.25, 0.05 | Абзацный отступ и допуск |
| | `alignment` | "" | `justify`, `left` или пусто (не проверять) |
| | `black_only` | true | Только чёрный текст |
| `[headings]` | `structural` | список ГОСТ | Какие заголовки считать структурными элементами, в нужном порядке |
| | `required` | содержание, введение, заключение, список источников | Какие элементы обязательны |
| | `new_page` | true | Структурные элементы и разделы с новой страницы |
| | `bold` | true | Заголовки полужирные |
| `[captions]` | `dashes` | ["–", "—"] | Какие тире принимать в подписях |
| `[references]` | `figures_and_tables` | true | Проверять ссылки на рисунки и таблицы |
| | `sources` | true | Проверять ссылки на источники |
| `[page_numbers]` | `check` | true | Проверять номера страниц |

Строки и списки в TOML пишутся в кавычках: `font = "Arial"`, `required = ["ВВЕДЕНИЕ", "ЗАКЛЮЧЕНИЕ"]`. Если меняете `structural`, перечислите список целиком: он заменяет список ГОСТ, а не дополняет его.
