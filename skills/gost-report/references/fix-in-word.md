# Как исправить в Word

Названия меню для Word 2016 и новее. Сначала правьте стили, а не отдельные абзацы: одна правка стиля «Обычный» исправляет шрифт, кегль, интервал и отступ во всём тексте.

| Код | Как исправить |
|-----|---------------|
| `margin`, `page-size` | Макет → Поля → Настраиваемые поля: левое 3 см, правое 1,5 см, верхнее и нижнее 2 см, «Применить: ко всему документу». Размер: Макет → Размер → A4. |
| `font`, `size`, `size-small`, `color` | Главная → Стили → правой кнопкой по «Обычный» → Изменить: Times New Roman, 14 (или сколько требует методичка), цвет «Авто». Если в отдельных местах текст вставлен с чужим оформлением: выделить и Ctrl+Пробел. |
| `spacing`, `spacing-exact`, `indent`, `align` | В том же окне стиля: Формат → Абзац: первая строка «Отступ» 1,25 см, междустрочный «1,5 строки», выравнивание «По ширине». |
| `page-number-missing`, `page-number-align`, `page-number-top` | Вставка → Номер страницы → Внизу страницы → Простой номер 2 (по центру). Номер из верхнего колонтитула удалить. |
| `page-number-title` | Двойной щелчок по колонтитулу → «Особый колонтитул для первой страницы». Если титульный лист не первый, поставить после него разрыв раздела (Макет → Разрывы → Следующая страница) и отключить «Как в предыдущем». |
| `new-page`, `empty-lines` | Вместо пустых строк: курсор перед заголовком, Ctrl+Enter. Лучше в стиле заголовка: Абзац → Положение на странице → «С новой страницы». |
| `title-case`, `title-align`, `title-dot`, `title-bold` | Заголовок структурного элемента: прописными, по центру, полужирный, без точки и без абзацного отступа. |
| `heading-*` | Стиль «Заголовок 1» (и «Заголовок 2» для подразделов) → Изменить: полужирный, выравнивание по левому краю, отступ первой строки 1,25 см, шрифт как у текста. Номер без точки: «1 Обзор», «1.1 Сравнение». |
| `figure-*`, `numbering`, `numbering-mixed` | Подпись под рисунком по центру без отступа: «Рисунок 1 – Название». Тире: Ctrl+минус на цифровой клавиатуре или Alt+0150. Удобнее через Ссылки → Вставить название, заранее создав подпись «Рисунок» и убрав точку и двоеточие: тогда номера идут подряд сами. Схема нумерации (сквозная или по разделам) одна на всю работу. |
| `table-*` | Название над таблицей, по левому краю, без отступа первой строки: «Таблица 1 – Название». |
| `figure-noref`, `table-noref`, `*-late` | Добавить в текст перед рисунком или таблицей: «показано на рисунке 1», «приведены в таблице 1». |
| `source-*`, `sources-uncited` | Номера в списке и в квадратных скобках должны совпадать; источники идут в порядке первых ссылок. Если источник добавлен в середину, перенумеруйте список и ссылки после него. |
| `appendix-*` | «ПРИЛОЖЕНИЕ А», «ПРИЛОЖЕНИЕ Б»…, без букв Ё, З, Й, О, Ч, Ъ, Ы, Ь. |
| `missing`, `order`, `alias` | Добавить недостающий элемент с заголовком по центру и расставить элементы в порядке из structure.md. Если название требует методичка, записать его в настройки (config.md), иначе переименовать как в ГОСТ. |
| `bold-body` | Если это заголовок, дать номер и стиль «Заголовок». Если выделение в тексте, убрать полужирный. |

После правки стилей сохраните файл и запустите проверку ещё раз.
