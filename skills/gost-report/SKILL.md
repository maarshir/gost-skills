# Оформление работы по ГОСТ 7.32-2017

Требования вуза сильнее ГОСТа: если у пользователя есть методичка, она главная, а ГОСТ закрывает то, о чём она молчит. Не выдумывай требований: каждое замечание связывай с пунктом ГОСТ 7.32 или методички, а если не уверен, так и скажи.

## Проверить готовый .docx

1. Спроси, есть ли методичка. Если есть, перенеси её отличия от ГОСТа (кегль, выравнивание, поля, названия разделов) в файл настроек по образцу `assets/methodichka-example.toml`. Все ключи описаны в [references/config.md](references/config.md).
2. Запусти проверку. Скрипт только читает файл и ничего в нём не меняет.
   ```bash
   pip install python-docx          # на Python 3.10 ещё tomli
   python scripts/check_docx.py работа.docx
   python scripts/check_docx.py работа.docx --config методичка.toml
   python scripts/check_docx.py работа.docx --json   # если удобнее разбирать
   ```
   Код выхода 1 значит «есть ошибки», 0 значит «ошибок нет» (замечания возможны), 2 значит «файл не прочитан». Файл `.doc` сначала пересохранить как `.docx`.
3. Перескажи результат по-человечески: сначала то, что исправляется разом для всего документа (поля, стиль «Обычный», номера страниц), потом точечные места. Место указано номером абзаца, началом текста и разделом: по началу текста его легко найти поиском в Word.
4. Для каждой ошибки дай способ исправить в Word из [references/fix-in-word.md](references/fix-in-word.md).
5. Назови, что скрипт не проверяет и что стоит посмотреть глазами (ниже).

Ошибки это прямые расхождения с ГОСТом или настройками. Замечания это места, где скрипт не уверен или ГОСТ допускает варианты: их показывай с оговоркой.

## Помочь написать или оформить с нуля

- Состав и порядок элементов, что писать во введении и заключении: [references/structure.md](references/structure.md).
- Все правила оформления с номерами пунктов: [references/formatting.md](references/formatting.md).
- Когда работа готова, проверь её скриптом, как описано выше.

## Что скрипт не проверяет

- Содержание: смысл заголовков, логику, объём разделов.
- Оформление каждой записи в списке литературы (скрипт проверяет только нумерацию и ссылки на источники в тексте).
- Титульный лист: у каждого вуза свой образец.
- Нумерацию и расположение формул; плавающие рисунки и надписи.
- Переносы в заголовках и висячие строки: они зависят от того, как Word разобьёт страницы.
